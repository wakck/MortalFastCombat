# 验证工具

`../Test.ps1` 在 Windows .NET Framework 上运行 20 项协程调度检查与 13 项记录持久化检查；不启动游戏。
`UninstallTests.ps1` 使用独立模拟目录检查卸载和清理，不操作正式安装。

`Validation*.cs` 是游戏内隔离测试工具的源码，不是正式插件，不应放进日常游玩的插件目录。
它们要求单独复制的测试存档、明确的测试标记、保存路径重定向和写入保护。
仓库不提供任何测试存档、原始运行日志、胜利记录或测试生成文件。
游戏内工具默认假设仓库位于游戏目录下的 MortalFastCombat；Build-Validation.ps1 同样使用该布局。
每次测试前必须确认读写仅指向隔离目录，退出进程后再移除测试 DLL 与标记。
历史对照结论见 ../docs/VALIDATION.zh-CN.md。
