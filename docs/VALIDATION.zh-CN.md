# 1.1.0 实现与验证报告

适配 Steam Build 26237817、Unity 2020.3.49f1、Windows x64 Mono。正式插件使用原有 BepInEx／Harmony 运行时补丁，原游戏 DLL 不变。

## 功能

- 保留 2／4／8 倍、Buff 空等待压缩和每帧 256 次／约 2 毫秒预算。
- 新增默认开启的精简提示：血条、内力条直接同步最终数值和满条状态，缩短数字与操作面板过渡，保留角色出招、真实响应和必要对话。
- 同周目、完整指纹一致的普通敌人，可在首条指令前手动跳过并调用本场原生胜利结算。不要求玩家属性相同，不模拟消耗，不重放旧奖励。
- 中途事件、条件结算、条件对话及无法完整识别的配置拒绝跳过。周目与胜利记录独立保存，支持未知旧档手动关联，原存档格式不变。

## 真实运行对照

实际分别加载备份的 1.0.1 与新版 DLL，使用同一份战斗副本、相同操作和逐回合种子，在相同目标帧率和分辨率下比较。测试入口显式核对实际时间倍率；早期未开启倍率的尝试不采用。实测约 59.8–60.0 FPS。

“后期”是原始瑞笙战；“普通规则夹具”是隔离运行中复制同一战斗、去掉脚本事件和敌方天赋的人工场景，用于较少 Buff 的对照，不能视为另一场未经修改的实际游戏遭遇。

| 场景／倍率 | 1.0.1 平均回合 | 1.1.0 平均回合 | 降低 |
| --- | ---: | ---: | ---: |
| 后期／4 倍 | 4.337 秒 | 4.034 秒 | 7.0% |
| 后期／8 倍 | 3.500 秒 | 3.269 秒 | 6.6% |
| 普通规则夹具／4 倍 | 2.931 秒 | 2.765 秒 | 5.7% |
| 普通规则夹具／8 倍 | 2.258 秒 | 2.108 秒 | 6.6% |

后期回合收尾分别从 1.599／1.453 秒降至 1.471／1.338 秒。血条协程每次平均等待约 2.3–2.9 帧，新版为 0 帧，达到界面等待降低至少 50% 的目标。仍有约数十微秒执行开销，不代表计算耗时归零；单协程计时可能并行，不能将其相加当作整回合收益。

后期两种倍率均在第 10 回合获胜，每组旧／新 **109 个状态检查点逐行一致，1,387 次移除通知逐行一致**。普通规则夹具均在第 6 回合获胜，每组 65 个状态检查点与 365 次通知一致。检查点包含血量、内力、Buff 层数／持续时间及随机状态。上述结果来自本地隔离测试；本仓库只公开汇总结论，不公开存档、原始回放或运行日志。

游戏受击抖动会逐帧使用全局随机数。严格对照仅在测试插件中隔离这部分表现随机数，正式插件不改随机系统；不同速度下普通游玩不保证重复相同随机结果。

## 专项检查

- 原调度器 20 项断言通过：顺序、次数、真实等待、未知迭代器、暂停、切换、共享预算、异常和清理。
- 记录模块 13 项断言通过：进程重读、跨槽关联、回读、新周目、旧档独立、合并、重复记录、原子写入／备份、版本不匹配和损坏处理；测试使用正式托管 JSON 编解码。
- 游戏内 33 项检查通过：血条变化／不变的最终显示一致，暂停及途中关闭精简正确；属性、技能、人物内部标识、Buff 存在、层数、持续时间和单位参数有差异时指纹不同；玩家变弱不改变敌人指纹。
- 验证了普通规则可跳过、条件结算／剧情事件拒绝、暂停和开关控制、重复点击与结算期间指令拦截。当前场景的一项原生胜利结果恰好执行一次，并返回剧情、恢复时间倍率。
- 记录真实游玩胜利，从 0 条增至 1 条；退出游戏进程后重新启动并读取同一副本，周目 UUID 和胜利记录均保留，再次匹配可跳过，跳过后记录仍为 1 条。重启前后记录已在本地核验，相关用户数据不随仓库公开。
- 原生空通知／实际响应夹具再次通过，分别保留空回调及真实等待、连锁增删和回调顺序。
- 更新脚本 5 项、回退脚本 5 项、卸载／记录清理脚本 12 项检查通过。卸载验证使用独立模拟安装目录；1.0.1 旧 DLL 另有实际启动对照。没有在正式安装目录执行完整卸载重装。

## 发现并修正的问题与验证边界

Unity 原生 JSON 接口遗漏插件自定义泛型列表，早期原型仅保留了记录头。已改用游戏提供的托管 DataContract JSON 序列化，并要求必需字段；实际文件及进程重启测试确认完整保留列表。早期错误文件仅属于测试用户，留作诊断，没有写入正式用户记录。

回放工具曾在异步重新载入时向退出中的旧战斗下达指令，导致首回合自动回放停滞；工具现排除旧管理器，异常尝试不采用，最终对照数据全部通过逐项一致检查。

命令行沙盒启动的测试进程无法初始化 Steam SDK，设置面板记录过原游戏的 Steam Deck 查询异常；战斗及原生结算完成正常。随后通过桌面启动检查过实际战斗设置面板。发现浅色背景上的状态文字不清楚后增加深色底；用户按 Esc 停止桌面操作，此处修正未再次截图，不再进行桌面输入。

## 交付与完整性

测试前核对 Save／Legend／Backup 路径重定向，并在保存入口拒绝隔离目录外的写入；保护持续到测试进程退出。测试用户独立于正式用户。

正式存档的 21 个数据文件及 3 个原游戏程序集在测试前后哈希全部一致，未执行正式存档恢复。完整性数据在本地保留，不随仓库公开。保留升级前的原倍率与配置，新增选项默认开启；正式插件／dist 指纹同步到安装清单。

测试 DLL、启动标记、临时开发启动文件从生效目录移除，测试胜利记录移到报告目录，避免混入用户记录。旧版本与配置只在原安装本地备份，不随仓库公开；卸载保留独立胜利记录，`Clear-History.ps1` 提供单独清理。
