# 1.1.3 验证汇总

本版增加跳过战斗快捷键和提示，不修改倍速、敌人指纹、胜利记录格式或原生奖励结算逻辑。

2026-11-01，在完整独立游戏副本与隔离存档中测试，Steam Build 26237817 / LOMAssistant 3.3.2 / BepInEx 6.0.0-be.789。

| 检查 | 结果 |
|---|---|
| 快捷键游戏内集成 | 47 项通过 |
| 既有跳过、敌人指纹及提示功能回归 | 33 项通过 |
| 按键状态机 | 16 项通过 |
| 协程调度 | 20 项通过 |
| 胜利记录持久化 | 13 项通过 |
| Buff 移除通知夹具 | 两组结果和回调一致 |
| 公开安装脚本模拟检查 | 32 项通过，覆盖安装/更新/回退/卸载及依赖、配置与记录保留 |

快捷键覆盖 F10 / R3、改为 F11 / South(A)、键盘/手柄独立禁用、长按进入可跳过状态不误触、暂停、设置面板、助手弹窗和文本输入保护、剧情战拒绝跳过、首条指令后禁用。

四次快捷键获胜均仅执行一次当前战斗原生奖励，返回剧情并恢复助手全局倍率；未下达普通战斗指令，跳过不新增胜利记录。默认 R3 的原生选择回调已安装限定拦截；只在接受跳过时消耗该输入。

测试预加载器在启动前重定向 persistent/cache 路径、禁止 PlayerPrefs 写入，SaveSystem 写入保护再次检查目标。测试前后及本地安装后，正式存档和正式胜利记录 30 个文件的 SHA-256、长度、修改时间及文件清单一致。正式游戏 DLL、助手和加载器未修改。

测试使用 Unity Input System 虚拟 Keyboard / Gamepad，隐藏窗口的焦点查询在测试副本中强制为 true。尚未测试实体手柄、蓝牙连接差异和自定义 Steam Input 映射。隔离环境 SteamAPI_Init 失败属于已知环境现象；最终完整测试无功能断言失败。本版没有重新执行整场速度基准，前版倍速验证见 [1.1.2 汇总](VALIDATION-1.1.2.zh-CN.md)。

发布包使用已完成上述游戏内测试的 DLL；旧版 .NET Framework 编译器每次构建可能生成不同 MVID，因此重新构建不保证 DLL 逐字节一致。源码和集成测试工具供审查；公开内容不含存档夹具、周目 UUID、胜利记录、原始日志或测试输出。
